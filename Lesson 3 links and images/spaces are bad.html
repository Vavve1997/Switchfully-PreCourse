Spaces are bad

This page is about spaces in file names. You can see that the file name for this page is spaces%20are%20bad.html. The spaces have been replaced with %20, which is the URL encoding for a space.

When you create files, it's best to avoid spaces in file names. Instead, use dashes or underscores. For example, instead of my file.html, use my-file.html or my_file.html.
